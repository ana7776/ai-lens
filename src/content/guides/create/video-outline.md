짧은 설명 영상을 만들어 보려고 AI에게 "OO 주제로 3분짜리 유튜브 대본 써줘"라고 하면 대본은 금방 나옵니다. 그런데 막상 카메라 앞에서 읽어 보면 문어체라 입에 붙지 않고, 화면에 무엇을 보여줘야 할지도 정해지지 않아 편집 단계에서 다시 막히게 됩니다. 영상은 말과 화면이 함께 움직이는 형식이라, 글처럼 대본만 먼저 완성하면 나머지가 따라오지 않기 때문입니다. 이 글은 1~3분 길이의 설명형 영상을 기획하는 과정만 다루며, 촬영 장비나 편집 프로그램 사용법은 다루지 않습니다. 핵심 메시지, 장면 구성안, 장면별 대본, 읽기 점검, 공개 전 확인 순서로 진행합니다. 다 읽으면 다음에 만들 영상 하나의 구성안을 바로 작성할 수 있습니다.

## 1단계: 시청자가 기억할 한 문장을 정합니다

짧은 영상일수록 전달할 수 있는 메시지는 하나입니다. 영상을 다 본 사람이 친구에게 한 문장으로 설명한다면 무엇이라고 할지 먼저 적습니다.

> 예시: "AI 회의록은 요약보다 '할 일·담당·기한' 표로 받아야 쓸모 있다."

이 문장이 정해지지 않으면 AI가 만든 구성안도 여러 이야기를 조금씩 담은 산만한 영상이 되기 쉽습니다.

## 2단계: 대본보다 장면 구성안을 먼저 받습니다

```
[주제] AI로 회의록 정리할 때 표 형식으로 받는 방법
[기억할 한 문장] (위 문장)
[대상] AI를 업무에 처음 써보는 직장인
[길이] 약 2분
[내가 가진 재료] 직접 만든 정리 양식, 화면 녹화 가능

장면 구성안을 표로 만들어줘.
열: 장면 번호 / 대략 길이 / 화면에 보일 것 / 말할 핵심 내용(1줄)
- 첫 장면은 10초 안에 시청자의 문제 상황을 보여줘.
- 내가 가진 재료로 보여줄 수 없는 장면은 '자료 필요'로 표시해줘.
- 대본 문장은 아직 쓰지 마.
```

구성안에서 확인할 것은 두 가지입니다. 장면마다 **화면에 실제로 보여줄 것이 있는지**, 그리고 모든 장면이 **기억할 한 문장**으로 이어지는지입니다.

### 구성안 예시

설명을 위해 만든 예시입니다.

| 장면 | 길이 | 화면 | 핵심 내용 |
|---|---|---|---|
| 1 | 10초 | 길게 늘어진 회의 요약문 | 요약은 읽었는데 할 일이 안 보인다 |
| 2 | 20초 | 요약문과 표를 나란히 | 같은 회의, 다른 형식 |
| 3 | 40초 | 요청문을 입력하는 화면 녹화 | 표 칸을 미리 정해서 요청 |
| 4 | 30초 | '미정' 칸에 형광펜 | 담당·기한이 없으면 미정으로 |
| 5 | 20초 | 체크리스트 3줄 | 공유 전 확인할 것 |

## 3단계: 대본은 장면별로 받습니다

구성안이 확정되면 대본을 장면 단위로 요청합니다. 영상 전체 대본을 한 번에 받는 것보다 장면마다 길이와 내용을 맞추기 쉽습니다.

```
장면 3의 대본을 써줘.
- 약 40초 분량, 말하는 속도 기준
- 대화하듯 말하는 문체, 한 문장은 숨 한 번에 읽을 수 있는 길이
- 화면에 요청문이 보이므로 요청문 전체를 읽지는 말고 핵심만 말하기
- 내가 해보지 않은 효과나 숫자는 넣지 마
```

## 4단계: 소리 내어 읽으며 고칩니다

대본은 눈으로 읽을 때와 소리 내어 읽을 때 전혀 다르게 느껴집니다. 휴대폰으로 녹음하며 한 번 읽어 보고 아래를 확인합니다.

| 확인할 것 | 고치는 방법 |
|---|---|
| 숨이 차는 긴 문장 | 두 문장으로 나누기 |
| 발음이 꼬이는 단어 | 쉬운 말로 바꾸기 |
| 화면과 말이 같은 내용 반복 | 말은 화면에 없는 설명으로 |
| 장면 길이보다 긴 대본 | 문장을 줄이거나 장면을 나누기 |

녹음 시간을 재보면 구성안의 길이와 실제 길이가 얼마나 다른지도 알 수 있습니다.

## 5단계: 자막과 설명란

대본이 확정되면 자막은 대본을 바탕으로 만들되, 화면에서 한 번에 읽을 수 있는 길이로 줄을 나눕니다. 영상 설명란에는 영상에서 다룬 내용의 요약, 참고한 자료의 출처, 관련 글 링크를 적어 두면 시청자가 내용을 다시 찾기 쉽습니다.

## 공개 전 확인

- **주장과 숫자:** 영상에서 말한 사실과 숫자는 [출처 검증 가이드](/work/research-sources/)의 순서로 확인합니다.
- **화면 속 자료:** 화면 녹화에 개인정보, 다른 사람의 이름, 알림이 보이지 않는지 확인합니다.
- **음악·이미지·폰트:** 각각의 이용 조건을 확인합니다. AI로 만든 음악은 [음악 브리프 가이드](/create/ai-music-brief/)의 권리 확인 항목을 함께 봅니다.
- **플랫폼 표시 규칙:** 업로드할 플랫폼에 AI 생성 콘텐츠 표시 규칙이 있는지 확인합니다.

## 자주 하는 실수

- **전체 대본부터 받기:** 장면과 화면이 정해지지 않아 편집할 때 다시 쓰게 됩니다.
- **문어체 그대로 읽기:** 소리 내어 한 번만 읽어 봐도 대부분 걸러낼 수 있습니다.
- **첫 장면에 인사와 소개 넣기:** 짧은 영상에서는 문제 상황을 먼저 보여주는 편이 시청자가 이어서 볼 이유가 됩니다.

## 체크리스트

- [ ] 시청자가 기억할 한 문장을 정했다
- [ ] 장면별로 화면에 보여줄 것이 있다
- [ ] 대본을 장면 단위로 받았다
- [ ] 소리 내어 읽고 녹음 시간을 확인했다
- [ ] 화면 속 개인정보와 자료 권리를 확인했다
- [ ] 영상 속 주장과 숫자의 출처를 확인했다

AI는 구성안과 문장을 빠르게 만들어 주지만, 영상이 시청자에게 남길 한 문장과 화면에 보여줄 실제 자료는 만드는 사람이 정합니다.
