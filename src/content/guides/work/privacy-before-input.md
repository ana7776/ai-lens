AI에게 일을 맡기려면 자료를 넣어야 하고, 업무 자료에는 대개 사람 이름, 연락처, 금액, 내부 사정이 섞여 있습니다. 급할 때는 "이 정도는 괜찮겠지" 하고 통째로 붙여넣기 쉬운데, 한 번 입력한 정보는 내 손을 떠나 서비스의 처리 방식에 따라 다뤄진다는 점을 기억해야 합니다. 어떤 정보가 문제가 되는지는 회사 규칙, 계약, 서비스 조건, 관련 법령에 따라 달라서 하나의 정답이 있지는 않습니다. 이 글은 입력 직전에 스스로 점검하는 일반적인 순서만 다루며, 법률 자문이나 특정 회사 정책을 대신하지 않습니다. 세 가지 확인 질문, 자료 유형별 점검표, 가명 처리 방법 순서로 설명합니다. 다 읽으면 다음에 자료를 붙여넣기 전 1분 안에 점검할 수 있는 기준을 갖게 됩니다.

## 넣기 전에 묻는 세 가지 질문

### 1. 우리 조직은 이 사용을 허용하는가

회사나 기관에 AI 사용 지침이 있다면 그것이 가장 먼저입니다. 허용된 서비스, 금지된 자료 유형, 승인 절차가 정해져 있을 수 있습니다. 지침이 없다면 담당 부서나 상급자에게 한 번 물어보는 것이 좋습니다.

### 2. 이 서비스는 입력한 내용을 어떻게 다루는가

같은 회사의 서비스라도 개인용·기업용 요금제, 설정에 따라 입력 내용의 저장 기간이나 서비스 개선 활용 여부가 다를 수 있습니다. 사용하는 서비스의 개인정보 처리 안내와 데이터 설정 화면을 직접 확인합니다. 무엇을 봐야 하는지는 [AI 도구 고르기 기준](/workflow/ai-tool-choice/)에서 더 다룹니다.

### 3. 이 자료에 무엇이 들어 있는가

같은 회의록이라도 내부 일정만 있는 경우와 고객 연락처가 들어 있는 경우는 전혀 다릅니다. 붙여넣기 전에 자료를 한 번 훑어 아래 점검표의 항목이 있는지 확인합니다.

## 자료 유형별 점검표

| 자료 유형 | 특히 확인할 정보 | 기본 처리 |
|---|---|---|
| 고객·회원 명단 | 이름, 연락처, 주소, 생년월일 | 넣지 않거나 가짜 예시로 대체 |
| 회의록·전사본 | 참석자 실명, 인사·평가 발언 | 역할명으로 바꾸고 평가 발언 삭제 |
| 계약서·견적서 | 상대방 정보, 금액, 비밀유지 조항 | 비밀유지 의무 확인 후 필요한 조항만 발췌 |
| 이메일 | 다른 사람의 주소, 이전 대화 인용 | 답장에 필요한 사실만 옮겨 적기 |
| 매출·재무 자료 | 거래처별 금액, 미공개 실적 | 구조만 남기고 숫자는 임의 값으로 |
| 개발 코드·설정 | 비밀번호, API 키, 접속 주소 | 반드시 삭제 후 입력 |
| 의료·건강·금융 관련 | 질병, 계좌, 신용 정보 | 승인된 환경이 아니면 입력하지 않기 |

이 표는 일반적인 출발점입니다. 업종에 따라 더 엄격한 규칙이 적용될 수 있습니다.

## 지우기, 바꾸기, 묶기

작업에 필요 없는 정보는 **지우고**, 사람이나 회사를 구분해야 하는 경우는 **바꾸고**, 정확한 값이 필요 없는 경우는 **묶습니다**.

| 방법 | 원래 정보 | 바꾼 정보 |
|---|---|---|
| 지우기 | 연락처 010-XXXX-XXXX | (삭제) |
| 바꾸기(가명) | 홍길동 과장, (주)가나다 | 담당자A, 거래처1 |
| 묶기(범주화) | 34세, 월 412만 원 | 30대, 400만 원대 |

가명을 쓸 때는 **대응표를 AI에게 주지 않습니다.** "담당자A = 홍길동" 같은 표는 내 컴퓨터에만 두고, AI의 결과를 받은 뒤 필요한 곳만 직접 실명으로 되돌립니다.

### 예시: 회의 메모를 넣기 전에

설명을 위해 만든 예시입니다.

```
[원래 메모]
홍길동 과장(010-1234-5678)이 가나다상사 김OO 부장과 통화.
단가 3,200원 → 2,950원 요청받음. 이 과장은 이번 분기 평가가 낮아서…

[넣을 메모]
담당자A가 거래처1 담당자와 통화.
단가 인하 요청을 받음(약 8% 수준).
```

평가에 관한 문장은 작업 목적과 관계없으므로 아예 지웠고, 정확한 단가는 비율로 묶었습니다. 이렇게 해도 "통화 내용을 정리하고 후속 할 일을 뽑는" 작업에는 충분합니다.

## 판단이 서지 않을 때

넣어도 되는지 확신이 없다면, 넣지 않는 쪽을 기본으로 합니다. 대부분의 경우 실제 자료 없이도 **방법**은 받을 수 있습니다.

- 정리 방법이 필요하면 → 형식만 같은 가짜 예시로 요청합니다.
- 문서 구조가 필요하면 → 목차와 각 부분의 역할만 설명하고 요청합니다.
- 문장 표현이 필요하면 → 민감한 부분을 [ ]로 비워 두고 요청합니다.

## 자주 하는 실수

- **"이름만 지우면 된다"고 생각하기:** 직책, 부서, 날짜, 사건이 함께 있으면 이름 없이도 누구인지 알 수 있습니다.
- **스크린샷을 그대로 올리기:** 화면 구석의 알림, 탭 제목, 메일 주소가 함께 들어가기 쉽습니다.
- **코드와 함께 키를 넣기:** 설정 파일을 통째로 붙여넣으면 비밀번호나 API 키가 함께 들어갑니다. 넣기 전 검색으로 `key`, `password`, `token` 같은 단어를 찾아보세요.

## 붙여넣기 전 1분 점검

- [ ] 조직의 AI 사용 지침을 확인했다
- [ ] 서비스의 데이터 처리 조건을 알고 있다
- [ ] 작업에 필요 없는 식별 정보를 지웠다
- [ ] 구분이 필요한 정보는 가명·범주로 바꿨다
- [ ] 가명 대응표는 입력하지 않았다
- [ ] 비밀번호·키·계좌 정보가 없다
- [ ] 판단이 서지 않는 자료는 가짜 예시로 대신했다

개인정보 보호는 AI 사용을 막는 절차가 아니라, 계속 안심하고 쓰기 위한 준비 과정입니다. 구체적인 법적 판단이 필요하다면 조직의 담당 부서나 전문가에게 확인하세요.
