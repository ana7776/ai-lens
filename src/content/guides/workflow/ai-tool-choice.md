새 AI 서비스가 나올 때마다 "이게 더 좋다"는 이야기가 들리고, 여러 개를 가입해 두었지만 결국 손에 익은 하나만 쓰게 되는 경우가 많습니다. 반대로 소개 글만 보고 유료 결제를 했다가, 정작 내 작업에는 맞지 않거나 회사 자료를 넣을 수 없는 조건이라는 것을 나중에 알게 되기도 합니다. 도구의 좋고 나쁨은 기능 목록보다 내가 맡기려는 작업과 조건에 맞는지로 결정됩니다. 이 글은 특정 서비스를 추천하거나 순위를 매기지 않고, 어떤 AI 도구를 고르든 확인할 일반적인 기준만 다룹니다. 일곱 가지 기준과 시험 과제로 비교하는 방법, 기록 양식 순서로 설명합니다. 다 읽으면 지금 고민 중인 도구 두세 개를 같은 기준으로 비교해 볼 수 있습니다.

## 먼저 맡길 작업 하나를 정합니다

"좋은 AI"를 찾기 전에 "무엇을 맡길지"를 정합니다. 회의록 정리, 이미지 제작, 영상 대본처럼 작업이 다르면 비교 기준도 달라집니다. 작업을 하나 정했다면 그 작업의 대표 사례를 **시험 과제**로 만들어 둡니다.

```
시험 과제 예시: 가짜 회의 메모(개인정보 없음) 한 개를 주고
"결정 / 할 일(담당·기한·근거) / 미정" 표로 정리해 달라고 요청
```

모든 후보 도구에 같은 시험 과제를 주면, 소개 글이 아니라 내 작업 기준으로 결과를 비교할 수 있습니다. 시험 과제에는 실제 업무 자료가 아니라 가짜 자료를 씁니다.

## 일곱 가지 확인 기준

### 1. 용도 적합성

시험 과제의 결과가 내 기준을 충족하는지 봅니다. 결과물의 정확성, 요청한 형식을 지켰는지, 모르는 내용을 지어내지 않았는지를 확인합니다. 한 번만 보지 말고 같은 과제를 두세 번 해보면 결과가 얼마나 일정한지도 알 수 있습니다.

### 2. 입력 데이터 처리

입력한 내용이 얼마나 보관되는지, 서비스 개선에 활용되는지, 이를 끌 수 있는지를 서비스의 개인정보 처리 안내와 설정 화면에서 확인합니다. 개인용과 기업용 요금제의 조건이 다를 수 있으므로 내가 쓸 요금제를 기준으로 봅니다.

### 3. 결과물 이용 조건

특히 이미지·음악·영상 도구라면 결과물을 공개하거나 상업적으로 쓸 수 있는 범위를 약관에서 확인합니다. 무료 요금제와 유료 요금제의 조건이 다른 경우가 있습니다.

### 4. 비용 구조

| 확인 항목 | 질문 |
|---|---|
| 기본 요금 | 월·연 단위 요금은 얼마인가 |
| 사용 한도 | 하루·한 달에 쓸 수 있는 양에 제한이 있는가 |
| 추가 요금 | 한도를 넘으면 어떻게 되는가 |
| 해지 조건 | 언제든 해지할 수 있는가, 환불 규정은 어떤가 |

### 5. 내보내기와 이동성

작업 결과와 대화 기록을 파일로 내보낼 수 있는지 확인합니다. 나중에 도구를 바꾸게 되더라도 그동안 만든 결과물과 요청문을 가져갈 수 있어야 합니다. 요청문은 도구 밖에 [템플릿 라이브러리](/workflow/prompt-library/)로 따로 관리하면 이 문제가 줄어듭니다.

### 6. 지원과 안정성

문제가 생겼을 때 도움을 받을 수 있는 경로(도움말, 문의 창구)가 있는지, 서비스 상태를 알려주는 페이지가 있는지 봅니다. 업무에 꼭 필요한 작업을 맡긴다면 서비스가 잠시 안 될 때 어떻게 할지도 생각해 둡니다.

### 7. 대안

이 도구가 없어도 같은 작업을 할 수 있는 방법이 있는지 적어 둡니다. 이미 쓰고 있는 프로그램의 기능이나 다른 서비스로 충분하다면 새 도구가 꼭 필요하지 않을 수 있습니다.

## 비교 기록 양식

```
비교일:
맡길 작업:
시험 과제: (가짜 자료 설명)

| 기준 | 도구 A | 도구 B |
| 1. 시험 과제 결과 | | |
| 2. 데이터 처리(확인한 안내 주소·날짜) | | |
| 3. 결과물 이용 조건 | | |
| 4. 비용·한도·해지 | | |
| 5. 내보내기 | | |
| 6. 지원 | | |
| 7. 대안 | | |

결정과 이유:
다시 확인할 날짜:
```

약관과 요금은 바뀔 수 있으므로 확인한 날짜를 꼭 적고, 몇 달에 한 번 다시 확인할 날짜도 정해 둡니다.

## 자주 하는 실수

- **기능 목록으로 고르기:** 기능이 많아도 내 작업에 쓰는 것은 몇 가지뿐입니다. 시험 과제 결과를 기준으로 합니다.
- **약관 확인을 미루기:** 결과물을 공개한 뒤 이용 조건을 확인하면 되돌리기 어렵습니다.
- **실제 자료로 시험하기:** 조건을 확인하기 전에는 가짜 자료로만 시험합니다.

## 체크리스트

- [ ] 맡길 작업 하나와 시험 과제를 정했다
- [ ] 모든 후보에 같은 시험 과제를 줬다
- [ ] 데이터 처리 조건을 공식 안내에서 확인했다
- [ ] 결과물 이용 조건을 확인했다
- [ ] 비용·한도·해지 조건을 확인했다
- [ ] 결과물과 요청문을 내보낼 수 있다
- [ ] 확인 날짜와 다시 볼 날짜를 기록했다

좋은 도구 선택은 가장 유명한 도구를 찾는 일이 아니라, 내 작업과 조건에 맞는 도구를 근거를 갖고 고르는 일입니다.
